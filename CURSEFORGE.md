# Don’t Die (At Your Desk)

Turn your **WoW Forever** adventures into movement breaks.

## Exercise triggers

| In-game event | Movement break |
|---|---|
| Level up | 20 star jumps |
| Discover a new area | 10 squats |
| Take a flight path | Stand up and stretch until landing |
| Full-party dungeon wipe | 10 push ups |

## Keep track of your progress

- **Done** records the current exercise as completed.
- **Skip** keeps the exercise owed for later.
- Each reminder lists your outstanding exercises.
- Skipping a flight adds one stretch break to repay later.
- History and outstanding work save per character between sessions.

Reminders stay hidden during combat. Flights take priority, with queued exercises waiting until you land.

## Commands

| Command | Action |
|---|---|
| `/dd` | Show command help |
| `/dd debt` | List outstanding exercises |
| `/dd history` | Show lifetime totals and the latest 10 completions |
| `/dd done` | Complete the current exercise |
| `/dd skip` | Dismiss the reminder while keeping the work owed |
| `/dd wipe` | Manually queue a dungeon-wipe exercise |
| `/dd test` | Queue a test reminder |

## Good to know

- Drag the reminder panel to move it.
- Ordinary zone changes do not count as discoveries.
- Automatic wipe detection requires visible, connected party members in a dungeon. Use `/dd wipe` when detection is unavailable.
- Flight breaks count automatically at landing unless skipped.
- Exercise completion is self-reported.
- Completing a test reminder counts toward your history.

**Built for WoW Forever. No external addon dependencies.**
